# 《云计算技术及应用》实践作业（三）：第5章 计算虚拟化

**作业性质：** 个人独立上机实践（开卷）  
**实验平台：** CNB 云端开发环境  
**实验时长：** 180分钟  
**作业总分：** 100分  
**提交方式：** 学习通作业附件，提交PDF实验报告  
**截止时间：** 以学习通本次作业页面显示为准

## 一、作业目标

结合第五章计算虚拟化的课堂内容，理解裸金属虚拟化、寄居虚拟化及容器化的区别，掌握 CPU、内存和 I/O 虚拟化的基本概念，并通过 CNB 在线终端完成 Docker 镜像、容器、资源配额配置和数据卷实验。

无需在个人电脑安装虚拟机、Linux或Docker Desktop。容器实验不代表已经创建 Xen、KVM 虚拟机。

## 二、实验平台与操作说明

课程仓库：https://cnb.cool/cloud-computing-lab/cloud-computing-hadoop-lab

学生需登录 CNB，使用教师安排的个人可开发仓库或独立工作区，进入“云原生开发”，打开 WebIDE 的 CNB 终端。不得全班共用一个可写的教师工作区。

在仓库根目录打开以下指导书：

labs/06-计算虚拟化综合实践.md

指导书包含全部操作命令、预计现象、思考题、提交与评分要求。每条命令均需独立执行，并保存真实运行截图。

## 四、提交要求

1. 每名学生独立完成实验，提交一份PDF报告。
2. 报告须包含班级、学号、姓名、实验目标、操作命令与真实运行结果，以及指导书规定的12张关键截图。
3. 报告须包含虚拟化架构对比图、思考题、实验中遇到的问题及处理方式，以及不少于200字的个人总结。
4. 文件命名：班级-学号-姓名-第5章实践作业三.pdf。
5. 通过学习通当前作业的附件上传入口提交，不接受仅发送图片或仅粘贴代码作为报告。

**特别说明：** CNB 当前 Docker 环境可以读取 CPU/内存配额的配置值，但不能据此确认内核已实施强制限额。任务五以配置观察、正确解释和机制分析评分，不要求进行CPU满载或内存耗尽测试。

请在操作过程中及时保存截图和报告。云端工作区关闭或回收后，临时容器及数据卷不保证长期保留。如出现平台访问、镜像下载、权限或 Docker 服务错误，保留终端原始报错并及时联系任课教师。
