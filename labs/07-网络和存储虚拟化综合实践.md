# 《云计算技术及应用》第6章实践作业（四）：网络与存储虚拟化综合实践

**实验形式：** CNB云端Linux + Docker虚拟网络与卷 + Python标准库模拟  
**适用对象：** 金融学、投资学本科学生；个人独立完成  
**实验时间：** 180分钟（两次90分钟）；**总分：** 100分  
**提交方式：** 学习通上传一份PDF实验报告（12张关键截图、分析题、架构图与总结）

## 一、实验目标与课堂内容对应

本实验紧扣第6章PPT的五个模块：网络虚拟化分类、虚拟网卡/虚拟交换/虚拟网络的实现方式、精简磁盘/快照/链接克隆、基于主机/存储设备/网络的存储虚拟化、云存储的对象/块/文件类型。

**实验边界：** Docker bridge是软件虚拟网络，不能直接等同于实体交换机、真实VLAN、OVS跨主机集群、VPN或SDN控制器。Python的快照/链接克隆/云存储是**概念示例**，不是真实存储阵列快照、SAN LUN或收费云存储。学生不需要安装任何本地虚拟机、Docker、OVS或VPN软件。

先查看现有网络：

~~~bash
docker network ls
~~~

启动两组教学虚拟网络和内网网页服务：

~~~bash
bash scripts/ch06/network-demo.sh setup
~~~

**情况A（待验证）**：如果显示 `MODE=BRIDGE_CANDIDATE`，说明已经创建网络，并且网页容器有可用形式的IP；**仍须执行下面的通信测试，不能直接判定通信成功**。

**情况B（自动备用）**：如果显示 `BRIDGE_UNAVAILABLE`、`BRIDGE_UNUSABLE` 或 `MODE=FALLBACK`，说明Docker自定义bridge创建失败，或虽然创建成功但容器没有有效IP，例如显示 `ContainerIP=invalid IP`。**这不是学生操作失败**，继续完成下面的测试命令，脚本将改用本机HTTP实验和软件访问规则示例，评分不受影响。不要运行sudo、privileged、安装OVS等命令。

查询状态：

~~~bash
bash scripts/ch06/network-demo.sh status
~~~

**截图3**：网络创建结果、网络状态，以及 `MODE=BRIDGE_CANDIDATE`、`BRIDGE_UNAVAILABLE` 或 `BRIDGE_UNUSABLE` 等实际输出。出现 `invalid IP` 时必须如实截图，不要写成网络已正常通信。

测试同一网络中的容器名称访问、另一个网络中的名称访问和无网络模式：

~~~bash
bash scripts/ch06/network-demo.sh test
~~~

**情况A真正通过通信测试时**，正常输出可能包含：

~~~text
CH6_NETWORK_OK
PASS: same-network service discovery and HTTP
MODE=BRIDGE_VERIFIED
OBSERVED: service name is not reachable from the second network.
~~~

注意：**仅通过另一网络无法解析或访问容器名称，不能严格证明所有IP层通信都已隔离。**

**情况B将自动进行本机回环HTTP备用实验**。示例输出：

~~~text
MODE=FALLBACK
Client class-A -> HTTP 200 CH6_FALLBACK_HTTP_OK
Client class-B -> HTTP 403 CH6_POLICY_DENIED
PASS: CH6 fallback HTTP and application-policy demo.
~~~

该备用实验通过Python标准库，在 `127.0.0.1` 上实际发出HTTP请求并根据请求头实施访问规则。**两次请求都使用同一个本机网络接口；403是应用层拒绝访问，并不等于Docker bridge、VLAN、VPN或内核层面的网络隔离成功。** 脚本还会尝试观察Docker `--network none` 和默认 `bridge` 模式的网络接口，若CNB限制这些操作，真实记录即可。

## 十一、常见问题

- **看不到scripts/ch06**：个人Fork没有同步第六章代码，先更新个人仓库或使用新仓库重新导入，切勿删除旧作业。
- **docker: command not found**：可能进入了普通Git终端；切换到CNB开发容器终端。
- **Cannot connect to Docker daemon**：截图并反馈教师，不要自行安装、启动或修改Docker守护进程。
- **BRIDGE_UNAVAILABLE / BRIDGE_UNUSABLE / invalid IP / bad address**：当前Docker虚拟网络不可用或未通过通信验证。按 `network-demo.sh test` 自动运行本机HTTP备用方案；不要求学生修改网络配置，不意味着本次实验失败。
- **Conflict: container name already in use**：先在已保存截图后运行本章清理脚本，再重试。
- **稀疏文件分配字节与同学不同**：底层文件系统会影响分配情况，属于正常差异。
- **云端页面关闭，数据不见了**：Docker卷不保证长期保存，个人截图、报告和作业PDF应及时下载到本地。
- **命令粘贴成一长串**：每次仅复制一条，执行完再输入下一条。

**安全提示**：不执行sudo配置网络、不安装VPN、不启动特权容器、不更改系统网卡或真实存储分区、不安装KVM/OVS、不输入个人金融账号或密码。遇到其他错误请保留完整终端输出联系教师。
